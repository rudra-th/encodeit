# EncodeIt 🚀

A sleek, fast, and developer-friendly web utility designed to handle all your text encoding, decoding, and hashing needs in one place. No data leaves your machine—everything is processed instantly in the browser.

🔗 **Live Demo:** [encodeit.netlify.app](https://encodeit.netlify.app/)

---

## ✨ Features

*   **Multi-Format Support:** Seamlessly convert text between popular formats like Base64, Hex, URL, HTML Entities, and Binary.
*   **Cryptographic Hashing:** Generate instant secure hashes including MD5, SHA-1, SHA-256, and SHA-512.
*   **100% Client-Side:** Your data is completely secure. No server-side storage, trackers, or databases are used—everything happens locally in your browser.
*   **One-Click Utilities:** Quick action buttons to instantly copy outputs, clear workspaces, or swap input/output fields.
*   **Responsive UI:** Fully optimized for both desktop and mobile layouts with a clean, distraction-free aesthetic.

---

## 🛠️ Tech Stack

*   **Frontend:** HTML5, CSS3 / Tailwind CSS, JavaScript (ES6+)
*   **Hosting & Deployment:** Netlify
